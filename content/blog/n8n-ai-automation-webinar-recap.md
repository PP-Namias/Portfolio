## Three-Phase Demo Breakdown

### Phase 1: Simple Automation (Beginner)

A webhook trigger connected to a Discord notification — 5 nodes total. This phase demonstrated how a single incoming event can automatically notify a team channel, eliminating the need for manual monitoring.

### Phase 2: Data Processing with APIs (Intermediate)

A scheduled API call that transforms data and sends it via email — 8 nodes total. Attendees saw how to bridge different APIs without heavy boilerplate code, using n8n's built-in transformation nodes to reshape data on the fly.

### Phase 3: AI-Powered Automation (Advanced)

A Google Form submission that triggers Gemini AI to generate a response, then distributes it across multiple channels — 12 nodes total. This was the highlight of the session, showing how AI can be embedded directly into automation workflows to create intelligent, context-aware systems.
