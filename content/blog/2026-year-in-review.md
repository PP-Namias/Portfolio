## Projects I'm Proud Of

### 1. This Portfolio

The biggest project of the year. This portfolio isn't just a website — it's a demonstration of engineering discipline:

- **278 tests** with Vitest and React Testing Library
- **100/100 react-doctor score** for code quality
- **19 CI/CD workflows** with GitHub Actions
- **Sanity CMS** for content management
- **AI chat** with streaming, RAG, and edge deployment
- **Security** with PentestAgent, gitleaks, and CSP headers

### 2. AI Chatbot at Wilshire Financial Network

Taking an AI chatbot from concept to production for a real client. The biggest lessons weren't technical — they were about reliability, communication, and expectations management.

### 3. Enterprise Automation

Automating document processing, HR onboarding, and data synchronization with n8n. Watching hours of manual work disappear into automated workflows never gets old.

### 4. Blog Content Strategy

Growing the blog from 3 posts to 14, spanning the full journey from first line of code to production engineering. Every post is designed as interview storytelling material.

## Lessons Learned

### 1. Build in Public

Every project I made public on GitHub created opportunities I didn't expect. Stars, forks, messages from other developers, and even client inquiries. The ROI of open source is immeasurable.

### 2. Testing Is Not Optional

The portfolio's 278 tests caught regressions constantly. Every refactor, every dependency update, every new feature — the tests told me when I broke something. I'll never ship untested code again.

### 3. AI Is a Tool, Not a Magic Wand

2026 was the year AI went mainstream in development. I learned to use it as a force multiplier — accelerating boilerplate, debugging, and exploration — while keeping my own understanding sharp.

### 4. Documentation Is Code

Writing blog posts forced me to understand my own work at a deeper level. If you can't explain it, you don't understand it well enough.

## What I'd Do Differently

### Start the Blog Earlier

I had 3 posts for most of the year. The blog wasn't a priority. When I started writing consistently — documenting projects, sharing lessons — everything changed. The blog became a portfolio piece in itself.

### More Client Projects

Client work teaches things personal projects can't: communication, deadlines, expectations, real user feedback. I want more of that.

## Looking Ahead to 2027

### Goals

1. **Deeper AI/ML** — move beyond API calls to training and fine-tuning models
2. **More open source** — contribute to projects I use daily
3. **Speaking** — more webinars, meetups, and conferences
4. **Mentoring** — help other junior developers navigate their journeys
5. **Sustain the blog** — keep writing at a consistent cadence

### Tech I'm Excited About

- **Agentic AI** — autonomous agents that can plan and execute multi-step tasks
- **Edge computing** — moving computation closer to users
- **TypeScript everywhere** — from frontend to backend to infrastructure
