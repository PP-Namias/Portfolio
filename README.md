## Quick Start

```bash
git clone https://github.com/PP-Namias/Portfolio.git
cd Portfolio && npm install
cp .env.example .env.local && npm run dev
```

Open [localhost:3000](http://localhost:3000). Sanity Studio runs on [localhost:3333](http://localhost:3333).

## Features

- **Modal-first UX** — Resume, Experience, Booking, Project Detail modals with Framer Motion
- **Sanity CMS** — 21 schema types, GROQ, multi-layer cache, visual editing, real-time preview
- **Secure media gateway** — HMAC-signed image proxy with 7-day TTL and unsigned fallback
- **AI chat** — Gemini with OpenAI failover and preset responses
- **Dark/light theme** — 8 accent color options via `next-themes`
- **Blog** — MDX with code highlighting, reading time, SEO meta
- **Gallery** — Masonry grid with lightbox and keyboard nav
- **CI/CD** — 19 workflows: lint, typecheck, 410 tests, react-doctor, PentestAgent, Trivy, CodeQL
