# Fix Stale Content

The **Stale** badge means a document has not been updated in 30+ days.

## Steps

1. Find the document by sorting the list view by "Last updated".
2. Open it.
3. Make any small edit (correct a typo, update a date, fix a link).
4. Click **Publish**.
5. The Stale badge disappears.

## Bulk fix
Use the **Vision tool** → "Stale content" saved query to get the list.
