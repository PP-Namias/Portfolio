# Add a Membership

## Steps

1. **Content → Pages → Profile → Memberships** → **Create new**.
2. Fields:
   - **Name** — required.
   - **URL** — required, https.
   - **Joined at** — date.
3. **Publish** — appears on `/#memberships` in the profile section.
