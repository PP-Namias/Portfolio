# Duplicate a Document

## Steps

1. Open the document.
2. Click the **••• menu** (top-right).
3. Click **Duplicate**.
4. A new draft is created with the same content. A new `_id` is
   generated. References are deep-copied.

## Caveat
The new document has no `slug` (regenerated on first save). Open it
and set the slug before publishing.
