# Content Review Skill

Reviews all content and copy in the portfolio — blog posts, section text, documentation, error messages — for clarity, consistency, grammar, and tone.

## When to use this skill

- Writing or editing blog posts
- Updating section copy (hero, about, connect)
- Reviewing documentation
- Writing error messages or UI labels
- Before merging any PR with user-facing text

## Workflow

1. **Spelling and grammar** — Check for typos, punctuation, and grammatical errors
2. **Tone** — Match the portfolio voice: professional, confident, approachable
3. **Consistency** — Same terms for the same concepts. No brand name drift
4. **Clarity** — Every sentence has one clear meaning. No jargon without explanation
5. **Brevity** — Cut unnecessary words. Favor short sentences
6. **Accessibility** — Alt text on images, descriptive link text, proper heading hierarchy
7. **Vercel copy rules** — Active voice, second person, numerals for counts, error messages guide the exit
