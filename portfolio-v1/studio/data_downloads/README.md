# Sanity Data Backup & Downloads

This directory holds database exports generated by the Sanity CLI. This directory is strictly ignored by Git (except for this README) to prevent massive datasets (`.tar.gz` and `.ndjson` files) from bloating the repo.

## How to Backup Production Data

Ensure you are located inside the `studio/` directory and run:

```bash
npx sanity dataset export production ./data_downloads/production-backup.tar.gz
```

Once exported, you can unpack the `.tar.gz` and inspect `data.ndjson` for content migrations logic.
